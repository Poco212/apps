# 🧩 Folder `js/components/` - Utility UI Components

Folder ini berisi komponen UI mandiri (*standalone UI controllers*) yang digunakan kembali di berbagai halaman aplikasi.

## Component Modules

- **`toast.component.js`**: Controller untuk menampilkan float notification popup (*Toast*) dengan pesan sukses, peringatan, atau bahaya.
- **`chart.component.js`**: Controller untuk melakukan kalkulasi rasio dan merender elemen bar chart mutasi persediaan secara dinamis pada layar dashboard.
