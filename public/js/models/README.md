# 📦 Folder `js/models/` - Data Models & Seed State

Folder ini memuat struktur entitas data dan data awal (*seed data*) aplikasi Warehouse App sesuai spesifikasi backend PDF (`UI UX/desain_backend_sistem_persediaan (1).pdf`).

## Modules & Responsibilities

- **`inventory.model.js`**:
  - Menyediakan initial state untuk array `barang`, `pemasok`, `karyawan`, `aset`, `barang_masuk`, `barang_keluar`, dan `aktivitas`.
  - Menyediakan mapping icon kategori visual untuk jenis barang persediaan.
